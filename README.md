# App-Receipt-Scanner

The app allows users to automatically process and extract information from gas station receipts.

### Features
- Manual and automatic (from a photo) data entry from gas station receipts.
- Show statistics based on receipt data.
- Full history of all records.
- Edit or delete any records.
- View gas stations and the types of fuel they offer on a map.

## So What I Learned

- Organizing the Development of a Multi-Feature Application.
- How to Use Firebase (Firestore & AI Logic).
- Combining UI elements with backend logic for a seamless user experience.
- How to Use and Integrate Mapbox Maps.
- How to Use the Google ML Kit - Document Scanner.
